# UI Guidelines for Nikhar Salon

## Strict Design Constraints
- **NEVER use the `Sparkles` icon** (from `lucide-react` or anywhere else) in this project.
- The user specifically requested that `Sparkles` must never be used because it gives an artificial/AI-generated feel.
- Instead of `Sparkles`, always use authentic, grounded, professional luxury icons:
  - For verified quality / authenticity: `BadgeCheck` or `CheckCircle2`
  - For premium products / awards: `Award` or `Crown`
  - For hygiene / safety: `ShieldCheck`
  - For salon craftsmanship: `Scissors`
